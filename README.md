# 🥗 Đồ án Web Thực phẩm & Giao hàng FreshGo

## 👥 Nhóm phát triển
1. **Trần Quỳnh Như** (Phân hệ Khách hàng)
2. **Zuns Nguyễn** (Phân hệ Admin)
3. **Hoàng Duy** (Phân hệ Quản lý Chi nhánh)
4. **Gia Kiệt** (Phân hệ Shipper)

## 🛠️ Công nghệ sử dụng
- C# ASP.NET Core Razor Pages
- Cơ sở dữ liệu: SQL Server
- Giao diện: HTML5, CSS3, Bootstrap 5

## 📂 Cấu trúc thư mục
- `Pages/`: Chứa giao diện và code xử lý của 4 phân hệ.
- `Database/`: Chứa file `FreshGo_Database.sql` dùng để khởi tạo cơ sở dữ liệu.

## 🚀 Hướng dẫn cài đặt cho thành viên nhóm
1. Kéo code từ nhánh `main` về máy.
2. Mở phần mềm SQL Server Management Studio (SSMS).
3. Mở file `FreshGo_Database.sql` và bấm `F5` (Execute) để tạo 8 bảng và dữ liệu mẫu.
4. Mở thư mục project bằng VS Code hoặc Visual Studio 2022 và chạy lệnh `dotnet run` để bắt đầu code.
